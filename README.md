# GTA Browser 3D

A small GTA-style 3D browser prototype built with Three.js.

## Run

Open `index.html` in a browser, or enable GitHub Pages for this repository.

No game-engine download is required. Three.js is loaded from a CDN.

## Controls

- WASD: move / drive
- Mouse: look
- Shift: sprint / faster driving
- E: enter or exit the red car
- R: reset
